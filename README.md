## 📅 Måndag: Formulär (P)

Idag går vi igenom hur vi bygger formulär i HTML. Vi tittar på olika typer av formulärfält, hur vi gör dem tillgängliga och användarvänliga samt hur vi kan validera det användaren fyller i direkt i HTML, utan JavaScript. Under lektionen bygger vi ett formulär tillsammans som vi sedan kan utveckla vidare med CSS.

### 🎯 Mål för dagen

* Skapa och strukturera HTML-formulär med rätt element och attribut.
* Välja och använda olika typer av formulärfält beroende på vilken information användaren ska fylla i.
* Bygga tillgängliga formulär med tydliga etiketter, grupperingar och hjälptexter.
* Använda HTML:s inbyggda validering för att kontrollera obligatoriska fält, format och tillåtna värden.
* Förbättra användarupplevelsen med lämpliga HTML-attribut och CSS för fokus och valideringsstatus.

## 📅 Fredag: Kodsnack

### Instruktioner
1. Alla ska ha sin kod uppladdat på ett publikt repo på sin github.
   
2. Senast kl 8 på morgonen postar alla länkarna till sina repon i resp gruppchatt. Ni har sen fram till kl 9.00 på er att studera koden och öva er på att förklara den för de andra.
   
3. Antingen klona repot eller läs direkt på GitHub den kod du ska redovisa. 
  * Den som står som nummer 1 i grupplistan, tittar på koden för den person som står som nr 2.
  * Den som står nummer 2 tittar på koden för person nr 3, osv...
  * Den som står sist i resp grupp, tittar på person nr 1's kod.

4. Efter morgonmötet går ni till era grupper och kör rundan med att förklara för de andra i gruppen.

5. Förklara inte all kod utan håll fokus på formuläret i första hand. Hinner ni kan ni även ta om personen använt min, max, clamp, färger eller annat från vecka som kan vara intressant.

6. Avsluta din presentation med:
   * 1 sak du tyckte var bra eller intressant med koden
   * 1 sak du tänker skulle kunna göra den ännu bättre

7. Avslutande diskussion - Diskutera i gruppen:
  * Hur var det att förklara någon annans kod, var det någon skillnad mot att förklara sin egen?
  * Hur var det att höra någon annan förklara er egen kod?

8. Återsamling - Sammanfatta er diskussion
   * Hur tyckte ni i gruppen att det var att prata om kod på det här sättet? Var det någon skillnad mot att presentera sin egen kod?

### 🎯 Mål för dagen

* Fördjupa förståelsen av veckans begrepp genom att prata kod.
* Kunna sätta sig in i någons annans kod och sedan kunna förklara den.
